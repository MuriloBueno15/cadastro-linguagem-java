# Cadastro de Linguagens de Programação

## Sobre o projeto

Projeto desenvolvido em Java como parte do meu plano de estudos para Desenvolvedor Java Júnior.

O programa utiliza ArrayList para armazenar linguagens de programação, consultar a quantidade de elementos e exibir uma lista numerada no console.

## Tecnologias utilizadas

- Java
- ArrayList
- Laços de repetição (for)
- Git e GitHub
- IntelliJ IDEA
- ## Funcionalidades

- Cadastrar linguagens de programação em uma lista.
- Exibir a quantidade total de linguagens cadastradas.
- Percorrer os elementos utilizando um laço de repetição.
- Exibir as linguagens em uma lista numerada.
-
## Exemplo de execução

```text
Total de linguagens é de: 4
1 - Java
2 - Python
3 - JavaScript
4 - C++
```

## Como executar

1. Tenha o Java JDK instalado no computador.
2. Clone este repositório usando o Git.
3. Abra a pasta do projeto no IntelliJ IDEA.
4. Execute o arquivo `src/Main.java`.
5. Visualize os resultados no console.
